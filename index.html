Abstract

Traditional long-horizon goal-point on-road navigation typically employs a two-stage paradigm with global path planning and local behavior decision-making. However, this approach relies on topological maps, which are inherently prone to information latency and incompleteness. Consequently, in regions that road frequently change or unmapped areas, pre-planned routes become unreliable. To address these challenges, we first propose a novel paradigm that coordinates global visual maps with local observations for navigation, with the the former provides on-road network layout for optimal routing and the latter assesses route feasibility. Next, we design an architecture based on multimodal language model that unifies the traditional two-stage pipeline into a single-stage, end-to-end framework. Meanwhile, to facilitate this research, we contribute a large-scale multimodal dataset with comprehensive sensor modalities. Finally, extensive experiments demonstrate that our method achieves state-of-the-art performance, validating its effectiveness over conventional approaches.
